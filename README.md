# 陈理想旅行日记 · 账号数据调研报告

旅行账号的数据研究展示网页，包含粉丝增长、受众画像、内容表现、运营建议与数据来源。

## 网页功能

- 自适应桌面与手机布局
- 绿色粒子背景与鼠标连线
- 滚动入场、图片悬停与阅读进度
- 可手动开启的背景音乐与音量调节
- 动效暂停及系统减少动态效果适配
- 数据下载与打印 / 保存 PDF

## 本地预览

在仓库目录执行：

```sh
python3 -m http.server 8765
```

打开 http://127.0.0.1:8765/ 。

## 发布

GitHub Pages 从 `main` 分支的根目录发布。更新并推送网页文件后会自动重新部署。

## 数据与素材

账号分析口径与时间范围见网页中的“数据来源”。公开抖音作品画面用于内容观察，原视频入口保留在作品区。背景音乐署名与来源见页面中的音乐信息。得意黑字体采用 OFL 1.1，许可证保留于 `assets/fonts/LICENSE.txt`。
